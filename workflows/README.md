# Workflows

This directory contains Markdown SOPs (Standard Operating Procedures) that define how tasks should be completed.

## Structure of a Workflow

Each workflow file should include:

1. **Objective** — What this workflow accomplishes
2. **Required Inputs** — What the agent needs before starting
3. **Tools** — Which scripts in `tools/` to use and in what order
4. **Expected Outputs** — What success looks like
5. **Edge Cases** — Known issues, rate limits, failure modes, and how to handle them
